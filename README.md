# 🎓 Unique Studyclub

> Where studying feels like a luxury.

Eine KI-gestützte Lernplattform für Studenten weltweit. Lernen, connecten und wachsen – alles an einem Ort.

-----

## ✨ Features

- 🤖 **KI-Tutor** – Lerne mit Groq AI (Llama 3). Frag alles, verstehe wirklich.
- 🤝 **Community** – Verbinde dich mit Studenten weltweit. Lerngruppen, Notizen, Fragen.
- 📬 **Daily Updates** – Tägliche Lerntipps und Challenges per E-Mail oder auf der Plattform.

-----

## 🛠️ Tech Stack

|Bereich         |Technologie       |
|----------------|------------------|
|Frontend        |React             |
|Backend         |Python + FastAPI  |
|Datenbank       |Supabase          |
|KI              |Groq API (Llama 3)|
|Hosting Frontend|Vercel            |
|Hosting Backend |Render            |
|E-Mails         |Resend            |

-----

## 🚀 Lokal starten

### Backend

```bash
cd backend
source venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --reload
```

→ läuft auf http://localhost:8000
→ API Docs unter http://localhost:8000/docs

### Frontend

```bash
cd frontend
npm install
npm start
```

→ läuft auf http://localhost:3000
